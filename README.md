# Algorithms

Решения задач по алгоритмам и структурам данных на PHP с тестами.

## Что внутри

### LinkedList
- `ListNode` — узел односвязного списка.
- `CycleDetector` — определение цикла (алгоритм Флойда, «черепаха и заяц») и поиск начала цикла.

### Queue
- `CircularQueue` — кольцевая очередь с фиксированной ёмкостью.

### Sort
- `QuickSort` — быстрая сортировка.
